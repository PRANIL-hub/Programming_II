#Quick Questions

1. What is the main difference between a list and a tuple?
->The elements in the list can be changed after it is created whereas It can not be done in tuple.

2. What is the convention for naming lists?
->Using plural nouns,lower case letters and avoid using build-in functions.

3. What would be a good name for a list of cities?
->"cities" would be a good name for a list of cities.

4. How many elements can you store in a list?
->Any amount of elements can be stored but the only limit is system's memory.

5. True or False? Elements in a list must all be of the same type (e.g. all strings or all integers)?
->False

6. What does Python's len function do? What types can it be used with?
->It returns the number of items in the  object passed.
