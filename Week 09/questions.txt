#Quick questions

1.Explain the difference between the 'r' and 'w' modes when opening a file.
->The difference is that 'r' mode opens the file in read mode only whereas 'w' mode opens the file in writing mode.

2.What is a file object and how is it different from a file name or the file's contents?
->A file object is an interface in Python (or other programming languages) that allows
  you to interact with a file on disk.
  It is different from the file name or the file's contents because file name is just a string and file contents
  is the actual data where as fiile object is like a tool to access the data.

3.Why is it necessary to close a file after it has been opened and used?
->It is necessary to close a file after it has been opened and used to ensure all data is properly saved.

4.What is a good principle for deciding whether a literal value should be stored in a CONSTANT?
->A literal value should be stored in a CONSTANT if it carries a specific meaning or is used multiple times.

5.Write a single Python expression that would evaluate to the file extension of a variable like
  filename = "this_is_a_name.txt" or filename = "document.docx" In those two examples, the result of the expression
  would be txt and docx respectively.
