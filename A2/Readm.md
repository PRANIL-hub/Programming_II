# Books to Read 2.0

## Description
This project is an updated version of the "Books to Read" program with both a console and GUI interface. It uses Python classes and Kivy for the GUI.

## Features
- Add, view, and toggle books as completed/unread.
- Sort books by title, author, or pages.
- Shows total pages left to read.
- Error checking for invalid input in GUI.

## Reflection
During this project, I learned:
- How to design classes (`Book` and `BookCollection`) for modular code.
- Using JSON for saving and loading data.
- Building dynamic GUI with Kivy and linking custom objects to widgets.
- Proper exception handling and input validation.
- Using Git version control and iterative commits for development.
